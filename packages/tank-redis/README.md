# @williamthorsen/tank-redis

A store adapter that keeps a `@williamthorsen/tank` balance in a Redis-compatible store. The adapter is not implemented yet; the package does not export anything.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add @williamthorsen/tank-redis
```

Node 24 or later is required.
