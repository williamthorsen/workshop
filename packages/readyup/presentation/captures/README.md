# Captures

Real output of the runs against which the deck's renderer is tested, one file per kit and state. The preflight run with both conditions off is the title slide's; the others cover the renderer's breadcrumb, nesting, multi-checklist, and findings paths. Each file holds exactly what the command printed, except `onboard-default.txt`, as noted below. Every run used readyup 0.42.0 built from this repository after the fix-hint glyph became 🔧.

`presentation/src/__tests__/captures.app.unit.test.ts` renders each kit in the state of each capture and compares the result with the file, ignoring durations and colour: line for line for preflight and adoption, whose models are complete, and for drift and onboard, whose models are partial, as the order in which their check lines, reason lines, and fixes appear. `preflight-11.json` is compared as parsed JSON. `adoption-probe.txt` is not compared, because the adoption model's conditions cannot reach its counts and findings. A recapture therefore requires updating the models to match: the preflight model in `presentation/src/kits.ts`, the others in `presentation/src/__tests__/fixtures/capturedKits.ts`.
