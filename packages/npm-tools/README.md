# @williamthorsen/npm-tools

A CLI that runs npm registry chores. Its commands are not implemented yet; the binary prints only its help and version.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/npm-tools
```

Node 24 or later is required.

## Usage

```bash
thor-npm --help
```
