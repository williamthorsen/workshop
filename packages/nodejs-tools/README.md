# @williamthorsen/nodejs-tools

A CLI that inspects Node.js runtimes and toolchains and prunes `node_modules` directories. Its commands are not implemented yet; the binary prints only its help.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/nodejs-tools
```

Node 24 or later is required.

## Usage

```bash
thor-node --help
```
