Setting one: the environment

Remove the three OpenAI variables, select the local voice, and check the repository's .env, which aidemo loads over the environment. 

$ unset OPENAI_API_KEY OPENAI_BASE_URL AIDEMO_OPENAI_BASE_URL
$ export AIDEMO_TTS_PROVIDER=local
$ grep --extended-regexp '^(OPENAI_|AIDEMO_OPENAI_)' .env
