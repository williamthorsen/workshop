$ AIDEMO_TTS_PROVIDER=local aidemo render demos/sample-tour --headless --strict
  1. voice Kokoro-82M, in process
  2. record headless Chrome replays the actions
  3. captions timed from the script
  4. compose ffmpeg trims, syncs, and muxes
  5. final-demo.mp4 with .srt and .vtt

local: the voice runs in process. --headless: no browser window. --strict: a compose warning fails the run.
