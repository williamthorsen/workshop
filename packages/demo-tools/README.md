# @williamthorsen/demo-tools

A CLI that renders and archives aidemo demos. Its commands are not implemented yet; the binary prints only its help and version.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/demo-tools
```

Node 24 or later is required.

## Usage

```bash
thor-demo --help
```
