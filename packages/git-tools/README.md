# @williamthorsen/git-tools

A CLI of utilities for working with git. Its commands are not implemented yet; the binary prints only its help.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/git-tools
```

Node 24 or later is required.

## Usage

```bash
thor-git --help
```
