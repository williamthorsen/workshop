# Changelog

All notable changes to this project will be documented in this file.

## 0.1.3 — 2026-10-26

### 🧪 Tests

- Adds the `s` flag to the pattern in the outside-a-repository test of `resolveCheckedOutBranch`, so that `.*` matches across a line break and the test accepts a git cause of more than one line. (#629)

### 📦 Dependencies

- Upgrades `vitest` and `@vitest/coverage-v8` from 4.1.12 to 5.0.5, and declares Vitest 5's required `vite` peer at 8.3.5 through the catalog in every workspace. (#632)

## 0.1.2 — 2026-10-22

### 📚 Documentation

- States in the `thor-git branch-number` help that `--min`, `--max`, and `--offset` can give two branches the same value, and that an identity takes the unbounded value while a slot, such as a port, takes a bounded one. (#623)

## 0.1.1 — 2026-10-17

### 📦 Dependencies

- Adds `vitest`, `@vitest/coverage-v8`, `typescript`, and `@williamthorsen/nmr` to the workspace catalog at the versions that the root `package.json` pinned, switches the root to `catalog:` for them, and declares `vitest` as a `catalog:` dev dependency in every package, plus `typescript` and `@williamthorsen/nmr` in `readyup`. (#602)

## 0.1.0 — 2026-10-11

### 🎉 Features

- Adds the `branch-number` and `ticket-ref` commands to `thor-git`, ported from `tb-git` in `@williamthorsen/toolbelt.git` with the same flags, output, and exit codes, which derive a stable number from a branch name and print the ticket that a branch name encodes, reading the checked-out branch when no branch is given. (#529)

### 🏗️ Internal features

- Adds the `@williamthorsen/git-tools` package with a `thor-git` binary, which prints its help for `--help`, `-h`, or no arguments and exits with code 2 on any other argument, to hold the `tb-git` port in #517. (#524)
