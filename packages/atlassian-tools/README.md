# @williamthorsen/atlassian-tools

A CLI for working with Jira Cloud from the command line. Its commands are not implemented yet; the binary prints only its help.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/atlassian-tools
```

Node 24 or later is required.

## Usage

```bash
thor-jira --help
```
