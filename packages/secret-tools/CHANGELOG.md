# Changelog

All notable changes to this project will be documented in this file.

## 0.1.1 — 2026-10-17

### 📦 Dependencies

- Adds `vitest`, `@vitest/coverage-v8`, `typescript`, and `@williamthorsen/nmr` to the workspace catalog at the versions that the root `package.json` pinned, switches the root to `catalog:` for them, and declares `vitest` as a `catalog:` dev dependency in every package, plus `typescript` and `@williamthorsen/nmr` in `readyup`. (#602)

## 0.1.0 — 2026-10-11

### 🎉 Features

- Adds the `set`, `get`, `has`, and `delete` subcommands to `thor-secret`, which act on a keychain secret named by a service and an optional `--account`, and exit 1 when the secret is not stored, 2 on a usage error, and 3 when the keychain cannot be reached, as `tb-secret` does. (#530)

### 🏗️ Internal features

- Adds the `@williamthorsen/secret-tools` package with a `thor-secret` binary, which prints its help for `--help`, `-h`, or no arguments and exits with code 2 on any other argument, to hold the `tb-secret` port in #518. (#525)
