# @williamthorsen/chrome-tools

A CLI that launches and manages Chrome debug sessions. Its commands are not implemented yet; the binary prints only its help.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/chrome-tools
```

Node 24 or later is required.

## Usage

```bash
thor-chrome --help
```
