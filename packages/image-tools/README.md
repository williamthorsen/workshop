# @williamthorsen/image-tools

A CLI that generates images in named styles from open-weight models. Its commands are not implemented yet; the binary prints only its help and version.

<!-- section:release-notes --><!-- /section:release-notes -->

## Installation

```bash
pnpm add -g @williamthorsen/image-tools
```

Node 24 or later is required.

## Usage

```bash
thor-image --help
```
