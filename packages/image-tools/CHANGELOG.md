# Changelog

All notable changes to this project will be documented in this file.

## 0.2.1 — 2026-11-27

### 🐛 Bug fixes

- Fixes the issue that `thor-image sprites` rejected a palette of 16 colours plus a transparent (`null`) entry, because it counted transparent entries toward the limit of 16 colours. (#1014)

## 0.2.0 — 2026-11-27

### 🎉 Features

- Adds the `thor-image sprites` command, which reads a JSON file of a palette and sprites, renders each sprite's frames left to right as one PNG strip, and prints a CSS rule per sprite that embeds the strip and sets `--frames` and `--last-x` for a `steps()` animation that rests on the last frame. (#1012)

## 0.1.0 — 2026-11-24

### 🎉 Features

- Adds `thor-image generate`, which places a subject into the prompt template of each `--style` named from `catalogue/styles.yaml` (or `--style all`) and renders it with `qwen-image-2.1-turbo` (the default, which also restyles `--reference` images and does not permit commercial use) or the Apache-2.0 `z-image-turbo`, through mflux run by `uv` on Apple Silicon. (#1008)
- Adds a `run.json` record that `generate` writes beside each run's images, stating per image the model, its licence, the mflux version, the full prompt, the seed, and the settings needed to reproduce it, and that `--json` prints on stdout, including the partial record of a run that failed partway. (#1008)

### 🏗️ Internal features

- Adds the `@williamthorsen/image-tools` package, whose `thor-image` binary prints only its help and version, and registers `image-tools` in the `scope:*` labels, the ESLint root-module allowlist, the README package table, and `AGENTS.md`. (#1007)
