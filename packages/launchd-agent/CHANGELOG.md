## 0.1.0 — 2026-10-15

### 🎉 Features

- Adds the `@williamthorsen/launchd-agent` package, which exports `installAgent`, `readAgentState`, `restartAgent`, and `uninstallAgent` for per-user launchd agents on macOS, and `renderPlist`, which returns the plist that `installAgent` writes without changing the machine. (#591)
- Makes `installAgent` wait until launchd has dropped an agent loaded under the same label before bootstrapping the new plist, which avoids the generic error that `launchctl bootstrap` reports when it runs while launchd is still dropping the previous instance. (#591)
- Sets the `PATH` of each rendered plist to Homebrew's bin directory, when Homebrew is found, followed by launchd's default `/usr/bin:/bin:/usr/sbin:/sbin`, and replaces that default entirely when the `AgentSpec`'s `environment` sets `PATH`. (#591)
